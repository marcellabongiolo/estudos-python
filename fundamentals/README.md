# 🧠 Fundamentos de Python

Módulo de estudos dedicado à base da linguagem Python e ao desenvolvimento de raciocínio lógico.

## Conteúdos

- sintaxe e tipos de dados;
- condicionais e estruturas de repetição;
- funções;
- coleções;
- tratamento de exceções;
- organização de código.

## Objetivo

Construir uma base sólida antes de avançar para algoritmos, automação e projetos maiores.

Este diretório é um espaço de estudo e será atualizado conforme novos exercícios forem adicionados.
