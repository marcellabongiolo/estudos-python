# ⚙️ Automação com Python

Módulo reservado para estudos de automação e scripts utilitários.

## Possíveis temas

- manipulação de arquivos e diretórios;
- processamento de dados;
- CSV, JSON e TXT;
- automação de tarefas;
- ferramentas de linha de comando;
- integração com APIs.

## Objetivo

Praticar Python em problemas mais próximos de tarefas reais de desenvolvimento e produtividade.

Os exemplos serão adicionados gradualmente conforme os estudos avançarem.
