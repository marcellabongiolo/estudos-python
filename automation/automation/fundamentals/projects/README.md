## 💎 About This Module

The **Projects** directory serves as a showcase for standalone, fully functional Python applications. Each subfolder or script here represents a complete micro-project built from scratch with an emphasis on user interaction and robust architecture.

### 🚀 Featured Highlights:
* **Planetary Weight Calculator (`peso_planetas.py`):** An interactive script that computes precise body weights across different planets of our Solar System based on surface gravity physics.
* **Interactive Terminal Apps:** Dynamic CLI applications featuring user inputs, formatted tables, and intuitive navigation loops.
* **Scalable Codebases:** Standalone architectures structured to easily expand into larger software systems.
